JetBrains사에서 만든 [[정적 타입 범용 프로그래밍 언어]]

Java와의 높은 호환성을 가지고 있다. Kotlin/JVM은 JVM 위에서 실행 되기 때문에 하나의 프로젝트에 Java와 Kotlin를 섞어서 사용할 수도 있다.

---

하나의 프로젝트에서 java/kotlin이 혼합이 가능한 이유

둘 다 JVM 위에서 돌아가기 때문이다.

Kotlin/JVM으로 컴파일하면 JVM bytecode가 만들어지기 때문에 실행 단계에서 Java로 작성했는지 Kotlin으로 작성했는지가 JVM 입장에서 중요하지 않다.

User.java       UserService.kt
    ↓ javac        ↓ Kotlin compiler
User.class      UserService.class
		   ↓
		   JVM

또한, Kotlin은 처음부터 Java interoperability를 염두에 두고 설계됐기 때문에, 대부분의 Java 코드를 Kotlin에서 자연스럽게 사용할 수 있다.

```java
public class User {
    private final String name;

    public User(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
```
Kotlin에서 User를 그대로 호출 가능
```kotlin
val user = User("Hojun")

println(user.name)
```

Java에서 Kotlin 코드 호출 또한 가능하다.

---

Java와 비교해 Null Safety에서 장점을 가지고 있다.

Java는
```java
User user = repo.findUser();

String name = user.getName();
```

`user`가 `null`이면 런타임에서 `NullPointException`이 발행하지만

Kotlin은
```kotlin
val user: User? = repo.findUser()

val name = user.name
```

이 코드 자체가 컴파일 되지 않는다.
`Only safe (?.) or non-null asserted (!!) calls are allowed`

```kotlin
val name = user?.name
```

또는
```kotlin
val user: User = ...
```
으로 null 가능성을 타입에 명시해야된다.
