## 정적 타입 프로그래밍 언어란?
코틀린 기준으로 설명

### 정적 타입 (static typing)
변수나 표현식의 타입을 프로그램을 실행하기 전에, 컴파일할 때 검사한다.

```kotlin
var age: Int = 20

age = "스무살" // 컴파일 에러
```

### 범용 (general-purpose)
특정 분야만을 위해 만들어진 언어가 아니다.

SQL은 데이터베이 질의를 위해, HTML은 웹 문서 구조를 표현하기 위해 사용. 반면, Kotlin은 여러 종류의 프로그램을 만들 수 있다.

Kotlin
├─ Android 앱
├─ 서버 / 백엔드
│   ├─ Spring Boot
│   └─ Ktor
├─ 데스크톱 앱
├─ 웹
└─ 멀티플랫폼 앱
