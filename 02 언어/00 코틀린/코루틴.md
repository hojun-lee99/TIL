비동기 작업을 스레드를 오래 붙잡지 않고 처리하면서 코드는 동기식으로 작성하는 방법

코루틴이 필요한 이유 = 비동기 작업이 필요한 이유

서버에서 외부 API를 호출한다.

```kotlin
fun getUser(): User {
	val response = externalApi.call()
	return response
}
```

외부 API에서 응답이 올때 까지 실행 스레드는 2초동안 대기하게 됨

```
Thread-1

요청 처리
   ↓
외부 API 호출
   ↓
████████████████ 2초 대기
   ↓
결과 처리
```

코루틴을 사용하면 다음과 같이 현재 작업을 중단해 실행 스레드를 다른 일에 사용할 수 있게 한다.

```
Coroutine A

코드 실행
   ↓
HTTP 요청
   ↓
suspend
```

그래서, 다음과 같이 실행 스래드가 코루틴 A가 suspend 되고 Corutine B를 실행할 수 있게 된다.


```
Thread-1

Coroutine A 실행
    ↓
HTTP 요청
    ↓
A suspend
    ↓
Coroutine B 실행
    ↓
Coroutine C 실행
    ↓
A 응답 도착
    ↓
Coroutine A resume
```

---

`suspend`를 함수 앞에 작성해 코루틴을 설정한다.

> 이 함수는 실행 도중 중단(suspend)됐다가 나중에 재개(resume)될 수 있다.

라는 의미를 가진다.

```kotlin
suspend fun getUser(): User {
	delay(1000)
	
	return User("hojun")
}
```

```
Coroutine
실행 → suspend ──────→ resume
         ↑
       Thread는
       다른 작업 가능
```

`luanch`와 `async`

`launch`: `Job`을 반환하고 결과값이 없다.
`async`: `Deferred`라는 결과값을 반환.

luanch
```kotlin
launch {
	sendEmail()
}
```
작업은 실행하고 결과값은 필요없음
반환값
```
Job
```

async
```kotlin
val user = async {
	getUser()
}

val result = user.await()
```
반환값
```
Deferred<User>

Java CompletableFuture<User> = Kotlin Deferred<User>
```
